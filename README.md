# 深圳周边高铁2小时直达旅游攻略

一个基于前端技术开发的单页面旅游攻略网站，专注于深圳周边高铁2小时内可达的城市，为用户提供详细的行程规划、交通方案、美食推荐和费用预算，助力轻松规划短途旅行。

## 🌟 项目特点

### 核心功能
- **城市概览**：覆盖东莞、惠州、中山、汕尾、佛山、珠海等10+深圳周边高铁2小时可达城市
- **详细行程**：每个城市提供2日游完整行程规划，包含上午/中午/下午/晚上的具体安排
- **费用透明**：清晰的交通、住宿、餐饮、门票费用统计，以及总花费核算
- **数据可视化**：通过Chart.js展示各城市高铁耗时，直观对比出行时长
- **旅行贴士**：提供元旦出行的实用建议（规划、装备、预算、交通、安全、拍照）

### 交互体验
- 城市卡片点击切换详情，平滑滚动定位
- 丰富的CSS动画效果（渐入、滑动、悬浮反馈）
- 响应式设计，适配手机、平板、桌面等多终端
- 玻璃拟态、渐变叠加等现代UI视觉效果

## 🛠️ 技术栈

| 技术/工具 | 用途 |
|----------|------|
| HTML5 | 页面结构搭建 |
| Tailwind CSS v3 | 样式开发（原子化CSS、自定义配置） |
| JavaScript | 交互逻辑、数据可视化、DOM操作 |
| Font Awesome 4.7 | 图标展示 |
| Chart.js v4.4.8 | 高铁耗时数据可视化 |

## 🚀 使用方法

### 本地运行
1. 将项目文件（单个HTML文件）保存到本地
2. 直接用任意现代浏览器（Chrome/Firefox/Edge/Safari）打开该HTML文件
3. 无需额外安装依赖，所有资源均通过CDN引入

### 操作指南
1. 页面加载后可查看所有高铁可达城市的概览
2. 点击对应城市卡片，可展开该城市的详细旅游攻略
3. 详细攻略包含：高铁信息、2日游行程、费用总结等核心内容
4. 页面下方可查看元旦旅行小贴士，助力出行规划

## 🎨 视觉设计

- **主色调**：蓝色（#3b82f6）为主，橙色（#f97316）为辅，搭配绿色（#10b981）作为点缀
- **视觉效果**：
  - 渐变叠加+文字阴影增强banner层次感
  - 玻璃拟态（backdrop-blur）提升交互组件质感
  - 卡片悬浮动效（hover:shadow-lg + translate-y-1）增强交互反馈
  - 时间轴式行程展示，清晰直观

## ⚠️ 注意事项

1. 页面中使用的图片均为网络图片链接，若出现图片失效，可替换为本地图片或有效链接
2. 响应式设计适配主流设备尺寸（移动端/平板/桌面端），建议使用现代浏览器访问
3. Chart.js图表在页面加载完成后自动渲染，若未正常显示可刷新页面
4. 所有费用数据为参考值，实际出行请以实时价格为准
